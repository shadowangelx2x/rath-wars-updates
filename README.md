# Rath Wars™ (रथ वॉर्स) — downloads & updates

The chariot duel of Kurukshetra. © 2026 Anmol Biswas (shadowangel). All rights reserved.

**Get the game:** open the [latest release](../../releases/latest) and download
- `RathWars.exe` — Windows PC (one file, double-click to play)
- `RathWars.apk` — Android

Already playing? The game updates itself: tap the blue **Update available** pill on the main screen.

This repository only hosts release files. It contains no source code.
